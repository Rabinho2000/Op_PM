# Perguntas em aberto

## Bloqueantes

1. O repositório deve continuar público ou deve passar a privado antes de receber código?
2. A organização usa Microsoft 365 empresarial com Entra ID, OneDrive/SharePoint e Exchange?
3. Qual é o programa Financial e que opções existem para integração: API, Excel, CSV ou base de dados?
4. Quais são os calendários e equipas que devem ser considerados no planeamento de visitas?
5. Quem aprova emails, visitas, pedidos de material, adjudicações e custos?
6. Qual é a regra oficial para os campos obrigatórios de um projeto?

## Importantes

1. Uma visita pode envolver mais do que uma pessoa ou equipa?
2. Quais são os horários, zonas geográficas, tempos de almoço e limites diários?
3. O cliente deve escolher diretamente uma data ou apenas receber propostas?
4. Que fornecedores devem ser suportados na primeira versão?
5. Como são recebidos e aprovados os orçamentos?
6. Qual é a estrutura atual da Drive e quem pode consultar cada documento?
7. Quantos anos de histórico devem ser migrados?
8. O fecho de visita/comissionamento deve ser bloqueado sem fotografias ou apenas gerar aviso?
